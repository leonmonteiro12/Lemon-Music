# 🍋 Lemon Music

A lightweight Android music player built by the Lemon himself. 🍋🎵

## ✨ Features

- 🎵 Music playback
- ▶️ Background playback
- 🔒 Screen-off playback
- 🔔 Media playback notification
- ⏮️ Previous / Next
- ⏯️ Play / Pause
- ⏩ Seeking
- 📱 Local music playback
- 🔎 YouTube music search
- 📋 Playlist support
- 🎤 Lyrics
- 🎧 Mini-player
- 🎶 Now Playing screen
- 🔀 Shuffle
- 🔁 Repeat
- 🔐 YouTube account integration

## 📱 Compatibility

Lemon Music is designed to support Android devices including older Android versions.

Minimum supported Android version:

**Android 6.0 (API 23)**

## 🛠️ Built With

- Kotlin
- Java
- Android SDK
- AndroidX
- Media3 / ExoPlayer
- YouTube Data API
- InnerTube components

## 🔐 API Keys & Secrets

No API keys, OAuth credentials, access tokens, signing keys, or passwords are included in this repository.
